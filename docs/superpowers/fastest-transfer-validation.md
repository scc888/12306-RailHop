# 最快中转：改动与验证

日期：2026-10-14；分支：`codex/fastest-transfer-20261014`。

## 使用方式

输入出发地、目的地与日期，检查两端实际车站勾选范围后，点击“查最快中转”。默认最多换乘一次，可扩大到最多两次；直达单独展示作对照。最快按首程出发至末程到达的总耗时计算，包含等待。收起详情仍显示实际经由站、等待、席别及跨夜等信息。

所选车站严格生效；默认驻马店范围选择驻马店、驻马店西，确山等同一行政城市下的其他车站可手动选择。城市成员来自12306字典，名称仅帮助初次勾选，不用于推断城市归属或保证市中心位置。

## 实现与兼容

- 按站对与日期合并查询，将响应用于所有可消费的真实前缀。任务按全程耗时下界调度，跨午夜和晚出发的较快路线保留。多个同城查询返回相同实际前缀时，先去重再计入状态预算。
- 候选发现复用最快入口已经刷新的公开车次信息，在所有已查询端点取得的车次中统一比较时刻，避免重复查询及早先站对的慢车独占候选名额；其他方向继续探测。
- 新增可选 `max_transfers`，搜索1至最大次数，共用既有预算；省略时旧 `transfer_count` 仍表示恰好次数。新增可选端点车站数组，必须非空、包含锚点，并经过官方城市归属校验。
- 新增 `mode=fastest`，不接受指定首程，强制按耗时查询，保留直达对照并跳过同车接续；现有查车次、单车次接续及旧中转调用保持可用。
- 个人最少换乘时间优先，严格实际同站和每段有票规则。部分区间失败传播给依赖该列车发现阶段的结果，不把刷新失败误判为车次失效或确定无票。
- 恢复默认设置取消在途请求并同步勾选范围；排序跨过分页边界后，展开状态及已选席别保留。
