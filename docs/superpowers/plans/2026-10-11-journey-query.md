# 城市出行查询改进计划

日期：2026-10-11。用户已授权检查并直接改进功能与 UI，范围仅查询。

目标：一次输入城市/车站、日期与席别，展示全程逐段有票的直达、同车接续、同站中转方案。默认智能查询：所选席别有直达票时先展示直达；无直达结果则续查两种替代方式。可主动查询全部或某一种方式。

技术：复用 Vue/FastAPI、官方站点字典、严格余票网关及现有中转算法，不增加产品依赖。

## 现状审查

1. 首页：直达与中转分离，旧页面强调买短补长、购买张数；“已就绪”是固定文案。桌面空态缺少查询说明。
2. 中转表单：重复城市/日期输入；手机查询按钮位于长表单底部。高级条件与必填条件同级。
3. 算法：旧同车方案只比显示车次，未严格核验运行日、实际站点、可售状态；跨午夜沿用起点日期；补长末段没有现票证据。

## 规则与约束

- 12306 现行公开规程第34条说明无运输能力可以拒绝越站补票和继续乘车，因此查询不把待补票区间算成可到达方案：https://kyfw.12306.cn/otn/gonggao/saleTicketMeans.html?linktypeid=means5
- 上海局官方同车接续说明：https://m.thepaper.cn/newsDetail_forward_29181361
- 中国铁路关于车次变化与重联列车换厢的说明（官方内容转载）：https://www.chinanews.com/sh/2026/05-28/10629996.shtml
- 每段均核验余票、实际站点和日期；同车需核验同一运行列车身份。同车分段不套用站内换车的15分钟；重联列车换厢可能须按工作人员指引经站台。
- 首末城市范围按官方字典城市字段分组，不按站名前缀。中途严格同站；沿用1～3次中转、指定站顺序和各站官方参考时间快照。
- 原12站资料候选及有界搜索公开披露；官方城市查询代表站返回不等于全国/城市站点穷举。不承诺全局最优或保证实时赶上车。
- 每段允许改选席别，以整数分合计，缺价为未知。默认不选无座；不分配座位号。
