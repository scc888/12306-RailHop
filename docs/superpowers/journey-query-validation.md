## 路线合理性策略与依据

采用 [GeoNames 城市坐标快照](https://www.geonames.org/export/)（CC BY 4.0），从发布方 `cities15000.zip` 提取与12306城市名称精确、无歧义匹配的332个城市。快照包含来源、日期、原归档SHA256和GeoNames ID；`backend/scripts/refresh_city_coordinates.py` 可重建。未查询用户地址，无运行时地理服务依赖。

- 地理距离是城市中心之间的大圆距离代理，不是铁路站点距离或铁路里程。默认候选及完整路线阈值为起终点代理距离的1.7倍+150公里，含等待的全程时间阈值为36小时与“代理距离/50公里每小时+12小时”中的较大值。适用于过滤明显折返，不承诺所有合理铁路走向都能保留。
- 对1～3次中转累计计算全程距离和耗时，先过滤，再按时长、到达时间或价格排序。北京→上海默认排除长春／长春西，仍允许南京南、郑州东等合理候选；默认的额外南京→天津折返也被排除。
- 手动指定站按顺序形成必要经由路径，额外自动站仍受该路径阈值限制，不能因指定一个正常站就绕过所有折返过滤。明确指定长春可查询并提示绕行；同站、余票和换乘时间不放宽。
- 扩大绕行选项默认关闭，开启后重新搜索并标注异常距离／耗时；仍受72小时与查询预算限制。
- 缺失或歧义坐标不按0处理：默认排除无法判断的自动候选；扩大范围可接受并提示无法核验。手动指定缺坐标站时只接受明确指定的中间站，不能自动加入无法判断的额外绕行。当前长沙同名地名有歧义，默认自动候选保守排除，可指定长沙南或主动扩大范围。

## 独立审查与修复

审查覆盖编排、运行身份、跨日、实际同站、城市解析、预算、状态、席别计价、请求取消与新补票／绕行策略。发现的问题已通过回归测试先复现失败、修复后通过：

1. 城市没有同名车站时无法查询：搜索城市归属字段，城市范围使用确定的官方分组代表站；单站范围仍要求准确站名。
2. 缺失停留时间或后段时刻异常误报确定空结果：改为partial并说明无法核验。
3. 指定顺路站意外豁免额外自动折返：改用指定站形成的必要路径作为手动例外的比较基准。

无已知未处理的Critical／Important审查项，无延后Minor项。

## 明确限制

当前中转资料12站；城市代表站响应并非全部站对穷举。同车阶段最多4个车次／16秒／40请求；补票备选最多4个车次／8秒／25请求；统一查询总预算60秒，中转阶段最多45秒／120请求／2000状态／50结果，行程72小时。达到上限时披露partial。站点参考时间为2026-10-10采集快照，通道开放、检票截止、晚点及现场补票能力仍以铁路安排为准。缺价保持未知，网站不分配座位号，不保证原席位延续、后续有座或全国最优。
